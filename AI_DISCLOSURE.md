# AI disclosure

smppkit adopts the [AI Disclosure Convention v0.1](https://github.com/ggfevans/ai-disclosure),
a voluntary community draft. The YAML frontmatter records the repository default;
per-file `SPDX-AI-Disclosure` comments take precedence for individual files.
The `SPDX-AI-*` fields use that convention's SPDX-style notation; this is not
a claim of official GitHub or SPDX certification.

## Model, tool and scope

- **Model:** GPT-6.0 Astra, confirmed by the maintainer on 2026-10-28.
- **Provider:** OpenAI.
- **Coding agent:** OpenAI Codex. The agent name and model name are distinct.
- **Default classification:** `ai-generated`. The implementation was primarily
  generated by AI in response to human requirements and feedback; it is not
  described as primarily human-written code with occasional AI assistance.

Every tracked Go file has an explicit disclosure, model, provider, scope and
date, including tests, benchmarks, examples and the optional legacy harness.
Scopes describe each file's role; they do not claim that only boilerplate was
generated. The model attribution follows the maintainer's confirmation and is
not a reconstructed per-edit telemetry history. No exact generation percentage
is claimed. The initial file-level declarations were added on 2026-10-28; future
changes should keep their dates and provenance accurate.

## Human involvement and review limits

The maintainer supplied requirements, constrained the public-library scope,
reviewed progress and directed corrections. AI agents implemented changes and
performed code review and validation. This does not assert an independent
line-by-line human audit of every file.

AI-authored tests and agent review can share mistakes with the implementation.
Independent protocol-byte fixtures are independent of the production serializer,
not a claim of independent human authorship or full standards certification.
Executed checks and their limitations are recorded in the
[validation history](docs/validation.md). The library itself has no AI runtime
dependency. Maintainers remain responsible for accepted changes and releases.

## Existing materials and license

The repository's standard [Apache-2.0 LICENSE](LICENSE) is preserved from the
initial repository; it was not authored by the model. Raw validation logs and
benchmark measurements are tool output collected during the work, not invented
AI results. Their surrounding explanations and summaries may be AI-authored.
External protocol documents and the legacy simulator are referenced with links;
this declaration does not claim authorship of those external works.

Adopting the disclosure format does not change smppkit's **Apache-2.0** license.
The convention's own CC0 license does not replace this library's license.
Existing release tags and historical validation artifacts are not rewritten by
the addition of these declarations.

## Keeping declarations accurate

When adding or changing a Go file, update its `SPDX-AI-*` comments to reflect the
actual model, provider, scope and latest AI involvement. Preserve existing GoDoc
and build constraints. If provenance differs from the repository default, record
the appropriate per-file override instead of copying an inaccurate declaration.
For example, human-authored code must not inherit a generated-code header merely
because a nearby file has one. If a model identity is unknown, document the gap
rather than inventing one; the convention permits omitting optional model fields.

Update this file when the repository's defaults or known model/provider inventory
changes. Contributors should disclose material AI involvement and review and test
their changes. Provenance declarations describe authorship, not a quality rating.
