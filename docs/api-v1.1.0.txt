package smpp // import "github.com/skill215/smppkit"

Package smpp implements general-purpose SMPP endpoints. A Session owns one
connection generation; reconnecting requires a new session and never replays
requests. Submission acceptance is separate from final message delivery.

func AdmitMessage(ctx context.Context, receiver *message.Receiver, in *Inbound, namespace string) error
    AdmitMessage admits and responds to one messaging request. ACK success
    means bounded memory admission only. The complete-message consumer runs
    separately through Receiver.Receive; its result cannot retract these ACKs.
    Explicit transaction submissions (mode 2) return ErrState before admission
    or response, leaving the handle available for application Respond. Memory
    alone cannot establish their delivery outcome. Use Receive/Respond for that
    mode. For mode 0, the caller must configure a non-transaction peer default.
    Delivery requests from the MC are not subject to this submission-mode
    restriction.

type Config struct {

	// the package never uses slog.Default. Client and Server setup also use it.
	// Handlers are called synchronously, outside Session locks, and must be
	// concurrency-safe and return promptly. They must not wait for operations
	// on the emitting Session (including Wait), since runtime loops emit logs.
	// The caller owns the logger and its output; the library never closes it.
	Logger            *slog.Logger
	Window            int           // 16 outbound requests, including queued writes
	InboundLimit      int           // 32 outstanding requests and queued responses
	NotificationLimit int           // 32 queued inbound notifications and 32 concurrent outbound Notify calls

	InboundTimeout    time.Duration // 30 seconds, closes unanswered sessions
	ReadTimeout       time.Duration // 2 minutes, includes partial frame acquisition
	WriteTimeout      time.Duration // 10 seconds per complete frame

	// disables scheduling; incoming enquiries are always answered while bound.
	// The interval starts again after each probe completes or is skipped because
	// the request window is full. Traffic does not reset it.

func (in *Inbound) Respond(ctx context.Context, status pdu.Status, body pdu.Body) error
    Respond validates a response before claiming the handle. Local validation
    or an already-cancelled context leaves it available for correction.
    After the claim, even a transport failure consumes the handle: blindly
    retrying an ACK could duplicate a response whose final peer-visible outcome
    is unknown. Cancellation after queue admission closes the originating
    Session. data_sm_resp fields are checked against the original request's
    direction/mode, independently of edits to PDU. Contextual validation does
    not claim the handle.

type Outcome uint8

func NewServer(cfg ServerConfig) (*Server, error)

func (srv *Server) Accept(ctx context.Context, conn net.Conn) (*Session, error)
    Accept takes ownership of conn, authenticates under the bind deadline,
    sends the response, and returns a bound session. TLS can be supplied by
    tls.Listener. Authenticate must return on context cancellation; no detached
    callback runs. Direct Accept callers must bound concurrency themselves;
    MaxConnections is enforced by Serve. The returned Session outlives the bind
    context.

func (srv *Server) Outbind(ctx context.Context, conn net.Conn, version pdu.Version, body *pdu.Outbind) (*Session, error)
    Outbind takes ownership of an already connected MC->ESME transport,
    sends outbind, then authenticates the peer's bind_receiver using Accept's
    admission path. Version must select a configured 3.4/5.0 profile; outbind
    has no version advertisement, so the peer must be configured consistently.
    RX is the supported outbind flow. The application owns dialing/listening
    and TLS role selection. One BindTimeout covers writing, reading and
    authentication. Failure closes the connection and is never retried;
    the outbind may already have reached the peer. Like direct Accept, callers
    must bound concurrent handshakes themselves.

func (srv *Server) Serve(ctx context.Context, ln net.Listener, handle func(context.Context, *Session)) error
    Serve accepts bounded concurrent connections. handle owns each bound session
    for its duration and must honor ctx. Cancelling ctx closes listener and all
    accepted connections; Serve joins handlers before returning.

type Session struct {
	// Has unexported fields.
}
    Session owns exactly one reader and writer. mu protects state, sequence,
    and independent inbound/outbound maps. No callbacks or I/O execute
    under mu. Inputs may be reused when Request/Notify returns. Receive and
    ReceiveNotification each have an independent single consumer. Other exported
    methods may be called concurrently. Do not mutate an input while a call uses

    not usable. Close then Wait joins the runtime, not application goroutines
    which may still be using returned values.

func Dial(ctx context.Context, address string, cfg ClientConfig) (*Session, error)
    Dial connects and binds. It never reconnects or retries requests. On success
    the caller owns the Session and should Close then Wait. Any transport opened
    by Dial is closed if connection setup or bind fails.

func NewSession(conn net.Conn, c *codec.Codec, cfg Config) (*Session, error)
    NewSession starts an unbound ESME on an existing connection (including TLS).
    Call Bind before messaging. For MC-initiated connections, receive/validate
    outbind through ReceiveNotification first, then bind as receiver. Failure to
    construct a Session leaves ownership of conn with the caller.

func (s *Session) Bind(ctx context.Context, b pdu.Body) (Result, error)
    Bind establishes the ESME role. The codec fixes the effective version;
    neither missing advertisements nor unknown version bytes trigger a fallback.

func (s *Session) Close() error
    Close aborts immediately. Wait joins all runtime goroutines.

func (s *Session) Done() <-chan struct{}
    Done closes when shutdown begins. Use Wait to join all runtime goroutines.

func (s *Session) Err() error
    Err returns the first terminal cause, or nil before shutdown.

func (s *Session) Notify(ctx context.Context, body pdu.Body) (Result, error)
    Notify sends alert_notification from a bound MC to an RX/TRX ESME. It uses
    the sole Session writer and sequence space, but no request window or pending
    response. For pre-bind outbind, use Server.Outbind instead. Other bodies are
    rejected. Success means Written, never peer acceptance or final delivery.
    Admission is bounded separately by NotificationLimit and RequestTimeout.
    Cancelling a queued write sends nothing; cancelling an active write closes
    the transport to expose its final byte count. No notification is retried.

func (s *Session) Receive(ctx context.Context) (*Inbound, error)
    Receive waits for the next application request; control traffic is handled
    internally. Use one consumer per Session and respond before InboundTimeout.
    Cancelling this wait does not close the Session or discard queued requests.
    Close discards inputs that have not been received; an already returned
    handle remains owned by the caller but cannot respond on a retired
    connection.

func (s *Session) ReceiveNotification(ctx context.Context) (pdu.PDU, error)
    ReceiveNotification returns an owned alert_notification or pre-bind outbind.
    Use one notification consumer independently of Receive/RunReceiver.
    Never ACK these packets: there is no response handle, inbound reservation or
    ACK timer. Cancelling this wait leaves the session and queued notifications
    intact. An outbind contains credentials: validate them before Bind with
    BindReceiver; on refusal Close the session. No automatic bind or credential
    logging occurs.

func (s *Session) Request(ctx context.Context, body pdu.Body) (result Result, err error)
    Request returns a result even on cancellation or transport failure.
    No request is retried. Cancellation during an active write closes the
    connection to make its final byte count observable; other pending requests
    may become uncertain. This also applies if a response arrives before Write
    returns. An already correlated response wins the request outcome (nil or
    PeerError), even when cancellation must retire the transport to join that
    write. Unbind additionally requires our ACK of a concurrent peer Unbind to
    finish. A successful submit_multi response can still contain Unsuccessful
    SMEs; inspect that list even when Request returns nil error. An ordinary
    submission ACK is not final delivery. For explicit transaction mode,
    interpret the peer's reported outcome using that request's semantics;
    no delivery tracking is added. An admitted Unbind retires the connection on
    completion or failure. If both peers initiate unbind, success waits for our
    response and the peer's ACK write.

func (s *Session) RunReceiver(ctx context.Context, receiver *message.Receiver, namespace string) error
    RunReceiver is the sole inbound consumer until it returns. It admits single
    parts and multipart messages, replies per segment, and sweeps expired groups
    every second. Consume completed messages with Receiver.Receive and events
    with Receiver.Events. On exit it closes the session; errors never discard
    already queued messages. Use AdmitMessage directly for a mixed-command
    dispatcher. The one-second expiry ticker is checked between admissions;
    a blocked ACK write can delay the sweep until that write finishes or its
    deadline expires. An unsupported transaction submission returns ErrState
    and closes the Session without admission or ACK; use Receive/Respond to
    implement transaction mode.

func (s *Session) SendText(ctx context.Context, msg TextMessage, policy message.Policy, references ...*message.References) (SendResult, error)
    SendText validates the entire message and every segment before the first
    write. policy must describe the peer's encoding/concatenation capabilities.
    Optional references overrides the session-scoped allocator, e.g. to share
    a sending domain across binds. At most one may be supplied; it is used only
    for multipart plans and must then be non-nil with the plan's reference
    width. Segments execute sequentially through Request's existing window;
    failure stops scheduling and retains every segment result. Neither a
    positive response nor this method's success implies final delivery.

func (s *Session) Shutdown(ctx context.Context) error
    Shutdown attempts unbind and then closes even if the exchange fails. Call
    Wait separately when all connection goroutines must have stopped. It does
    not drain application requests; finish that work before initiating shutdown.

func (s *Session) State() State
    State returns a synchronized snapshot, not a reservation for a later call.

func (s *Session) TLVEnabled() bool
    TLVEnabled reports negotiated optional-parameter support. A missing bind
    advertisement never silently enables TLVs, even with a 3.4/5.0 codec.

func (s *Session) Wait()
    Wait joins the reader, writer, expiry loop and optional heartbeat scheduler;
    it does not initiate shutdown.

type State uint8
    State is a snapshot of one connection generation; Closed is terminal.

const (
	Connected State = iota // transport open, no successful bind yet

FUNCTIONS

func ReadBind(r io.Reader, maxFrame int) (pdu.PDU, pdu.Version, error)
    ReadBind is the bounded server bootstrap. It accepts only bind requests and
    exact version bytes 0x33, 0x34, 0x50; no compatibility alias is inferred.
    Profiles are selected by the server after this operation, before any
    response.

func ReadFrame(r io.Reader, maxFrame int) ([]byte, error)
    ReadFrame reads one bounded raw frame without interpreting command/body
    fields. maxFrame defaults to 64 KiB; accepted limits are 16 bytes through 16
    MiB. The length is checked after four bytes, before allocating the remaining
    frame. Invalid configuration consumes nothing. Invalid lengths consume only
    four bytes and are not drained; there is no resynchronization or automatic
    retry.

    The result owns exactly the received prefix, including on errors;
    len and cap exclude unread storage. Empty EOF returns nil data. DecodeError
    records exact progress; errors.Is/As preserve the I/O cause. An EOF cause
    after the length prefix is NOT a clean frame boundary: inspect BytesRead,
    not EOF alone. Complete acquisition does not imply semantic validity. Call
    Codec.Decode to validate, or apply an explicit application policy before
    forwarding raw data.

    The caller owns deadlines, cancellation, serialization of reads on a stream,
    and the connection lifecycle. No logging, ACK, sequencing or heartbeat
    occurs.

func WriteFrame(w io.Writer, src []byte, maxFrame int) (n int, err error)
    WriteFrame validates only the length/cap and makes one Write of the exact
    raw frame, without allocation/copy or semantic validation. Limits match
    ReadFrame. Malformed/unknown body fields are unchanged; forwarding policy is
    the caller's. The caller must keep src immutable until return and serialize
    transport writes.

    n is the writer's actual progress. A short write with nil error becomes
    io.ErrShortWrite; non-nil writer errors are preserved even if n == len(src).
    Invalid configuration/frame length returns n=0 and wraps ErrValidation
    before I/O. No retries or flush are performed; buffered writers require
    caller Flush. A partial write may invalidate the connection; never retry the
    whole frame merely because this function returned an error. Writer counts
    outside the io.Writer contract are rejected with io.ErrShortWrite and n=0.

    Standard byte fields may share one owned body allocation, but each field's
    capacity ends at its length: appending cannot overwrite a sibling field.

func (c *Codec) ValidateDataDirection(body pdu.Body, direction DataDirection) error
    ValidateDataDirection adds contextual checks for DataSM/DataSMResp to an
    ordinary Append or Decode. Call it in addition to normal encoding/decoding:
    it does not replace framing, width, value, dependency or customer
    validation. Without this explicit context, Codec continues to accept the
    direction union. Omitted data_sm_resp is supported; other bodies, nil and
    unknown directions are rejected. Unknown/customer tags have no inferred
    direction restriction. For a response with original-request mode context,
    use ValidateDataResponse. This method is read-only, concurrency safe and
    never invokes user callbacks.

    ValidateDataDirection. Save requestESMClass before handing an owned request
    to application code. This does not validate framing, sequence correlation,
    field widths, or customer definitions; callers must still use Append/Decode.
    No user callbacks run here. A zero mode means an unknown MC default, not
    necessarily store-and-forward. Delivery requests do not reveal the original
    submission's messaging mode.

type Field struct {
	Tag   uint16
	Value []byte
}
    Field stores a tag and raw value without a caller-controlled wire length.

type Fields []Field

func (f *Fields) ReplaceFirst(tag uint16, value []byte) bool

package textcodec // import "github.com/skill215/smppkit/textcodec"

Package textcodec implements strict text conversion. GSM7 represents unpacked
septets, never guessed packed bytes. UCS2 rejects supplementary characters;
UTF16BE is an explicit compatibility encoding with the same DCS value.

VARIABLES

var ErrEncoding = errors.New("smpp: unrepresentable or invalid text")

FUNCTIONS

func Validate(e Encoded) error
    Validate checks boundary offsets, not alphabet membership or DCS semantics.
    It borrows e without mutation; the custom encoder still owns text
    correctness.


TYPES

type Alphabet uint8
    Alphabet selects a built-in strict converter. The zero value is invalid.

const (
	GSM7 Alphabet = iota + 1
	Latin1
	UCS2
	UTF16BE
)
func (a Alphabet) DataCoding() uint8
    DataCoding returns this encoding's SMPP 3.4/5.0 DCS assignment. Latin1's
    value 3 is not a Latin-1 mapping in SMPP 3.3's GSM DCS; message.Prepare
    rejects that built-in combination. UCS2 and UTF16BE both use 8, so the
    receiver must choose its interpretation explicitly.

func (a Alphabet) Decode(b []byte) (string, error)
    Decode rejects malformed escapes, odd two-byte data and invalid surrogates;
    it never guesses a different encoding or returns a partially decoded string.

func (a Alphabet) Encode(s string) (Encoded, error)
    Encode converts valid UTF-8 without replacement characters or partial output
    on failure. Boundaries include complete GSM escapes and UTF-16 surrogate
    pairs.

func (a Alphabet) Name() string
    Name is a diagnostic encoding label, not a value sent on the wire.

func (a Alphabet) UnitBits() int
    UnitBits distinguishes unpacked septets from octets for radio budgeting.

type Encoded struct {
	Bytes      []byte
	Boundaries []int
}
    Encoded records safe end offsets for indivisible characters. Boundaries are
    strictly increasing and end at len(Bytes), or are empty for empty input.

type Encoding interface {
	Name() string
	DataCoding() uint8
	UnitBits() int
	Encode(string) (Encoded, error)
	Decode([]byte) (string, error)
}
    Encoding implementations must be concurrency safe and return owned storage.
    Decode must not mutate or retain its input. Callbacks are synchronous
    trusted code; callers must bound their work and allocation, including on
    errors. UnitBits is 7 for unpacked GSM septets, 8 for octet encodings.
    Every output byte consumes one unit; Boundaries must preserve multi-unit
    characters. DataCoding is an explicit peer/profile mapping, not version
    negotiation. Custom implementations used by message.Prepare must choose a
    DCS appropriate to that version; the planner can infer compatibility only
    for built-ins.


package message // import "github.com/skill215/smppkit/message"

Package message prepares text, assembles received segments, and optionally
parses or constructs receipt evidence without owning a transport. Submission
acceptance, later receipt content and receipt ACKs are distinct outcomes.

VARIABLES

var (
	ErrCapacity = errors.New("smpp: message resource capacity exceeded")
	ErrMetadata = errors.New("smpp: invalid or conflicting message metadata")
	ErrConflict = errors.New("smpp: conflicting segment")
)
var ErrNotReceipt = errors.New("smpp: body is not an explicitly marked receipt")
    ErrNotReceipt means the body is not deliver_sm/data_sm with an explicit MC
    receipt or intermediate-notification type. Text or a receipt TLV alone never
    classifies an ordinary message as a receipt.

var ErrUnsupportedNationalLanguage = errors.New("smpp: UDH national-language tables are unsupported")
    ErrUnsupportedNationalLanguage reports an unsupported UDH language-table
    declaration (IE 0x24 or 0x25). Prepare rejects these before encoding.
    Receive reports this in Message.DecodeError only when text decoding was
    requested; raw payload and per-segment provenance remain available. This
    also applies to custom encoders and explicit default-table declarations.
    Raw Codec operations and raw-only reception remain available without table
    inference.


FUNCTIONS

func BuildReceipt(spec ReceiptSpec, options ReceiptBuildOptions) (pdu.Body, error)
    BuildReceipt creates an owned existing concrete DeliverSM or DataSM body.
    It creates no connection, timers, correlation, ACK, retries or persistence.
    Format-specific checks use ErrMetadata; full protocol checks reuse a
    standard versioned Codec and return its errors. No custom TLVs are supplied
    here: callers may add them afterward and validate with their configured
    Codec/Session. There is no partial output on error. Nil Text in a
    text-bearing format emits only explicit id/stat; missing optional fields are
    not fabricated.

func Prepare(version pdu.Version, msg Text, policy Policy) (*Plan, error)
    Prepare encodes all text before segmenting at safe character boundaries.
    It performs no I/O or reference reservation. Codec-specific field/TLV

    selected table.

}
    ReceiptSpec is caller-provided report evidence. MessageID is opaque,
    never generated or radix-normalized: 1..64 non-NUL ASCII octets for
    TLV-only output, further restricted to a token by text formats. State
    is message_state; it does not infer success from an earlier submission
    response. Source/Destination are the report addresses, normally reversed
    from the original message. Kind and State remain distinct; the helper does
    not decide delivery finality. Text is legal only in text-bearing formats;
    NetworkError only in TLV formats.

type ReceiptTLVs struct {
	MessageID    string
	HasMessageID bool
	State        uint8
	HasState     bool
	NetworkError *ReceiptNetworkError
}
    ReceiptTLVs exposes only uniquely present, structurally valid values.
    Unknown numeric states/network types remain available with Unsupported
    diagnostics. Duplicates are never silently resolved; all original TLVs
    remain in Optional.

type ReceiptText struct {
	Source   string
	TLVIndex int
	Raw      []byte
	Fields   []ReceiptField
}
    ReceiptText describes one text carrier. Raw owns the encoded payload. Fields
    contain decoded strings only for an explicitly selected, supported dialect.
    TLVIndex is -1 for short_message, otherwise its original optional-field
    index.

func (r ReceiptText) Value(name string) (value string, unique bool)
    Value returns a uniquely present field, including a present empty text
    field. Missing or duplicate fields return false; malformed/unsupported
    values remain observable and must be interpreted alongside
    Receipt.Diagnostics.

type ReceiptTextSpec struct {
	Submitted, Delivered, SubmitDate, DoneDate, Error string
	Text                                              *string
}
    ReceiptTextSpec contains optional dialect fields. Empty scalar strings omit
    fields, rather than inventing counts or timestamps. Counts, when supplied,
    are three digits; dates are ten-digit YYMMDDhhmm civil components,
    with no century or zone interpretation. Error is an opaque 1..32 byte token.
    Text nil omits the field; a pointer to "" emits an explicitly empty field.
    Text is at most 20 printable ASCII characters; nothing is truncated.

type ReceiveConfig struct {
	AckPolicy         AckPolicy     // must be AckOnBuffered; persistence belongs to the application
	MaxGroups         int           // incomplete groups, default 1024
	MaxBytes          int           // retained segment and assembled-payload charges, default 8 MiB
	MaxMessageBytes   int           // segment-storage charges per message, default 128 KiB
	MaxSegments       int           // declared concatenation total, default 255
	QueueSize         int           // completed messages waiting for Receive, default 32
	MaxTombstones     int           // retained completed-message signatures, default 1024
	EventLimit        int           // expiry events waiting for Events, default 128
	Lifetime          time.Duration // from first segment admission, default 5 minutes
	TombstoneLifetime time.Duration // from completion, default 5 minutes
	// DCS interpretation is explicit. Nil retains binary content without decoding.
	// A UDH national-language declaration prevents text decoding, including with
	// custom codecs; Receive retains the content and reports DecodeError instead.
	Encodings map[uint8]textcodec.Encoding
}
    ReceiveConfig bounds collecting and completed messages. Zero numeric limits
    use defaults; AckPolicy must always be explicit. Byte charges are accounting
    estimates, not a process heap ceiling, and exclude data handed to the
    caller.

type Receiver struct {
	// Has unexported fields.
}
    Receiver is a bounded, concurrency-safe memory store. Admit atomically
    commits segment and completion queue admission. Receive transfers ownership
    out of its resource budget. Expire must be called periodically; event
    pressure retains state and returns ErrCapacity instead of silently dropping
    evidence. Conflicts/capacity/malformed inputs are returned synchronously by
    Admit.

func NewReceiver(cfg ReceiveConfig) (*Receiver, error)
    NewReceiver starts no goroutines. Its owner must call Expire and drain
    Events; the smpp Session.RunReceiver adapter supplies the periodic expiry
    sweep. The encoding map is copied; Encoding implementations remain shared
    trusted objects. Receive invokes Decode outside the receiver lock after
    transferring the message out of the budget, so consumers must bound their
    own retained data.

func (r *Receiver) Admit(namespace string, fields pdu.SMFields, now time.Time) (Admission, error)
    Admit requires an explicit namespace, normally one session generation.
    Share a namespace and Receiver across binds only when their tenant scope
    permits it.

func (r *Receiver) Events() []Event
    Events transfers all currently recorded events to the caller.

func (r *Receiver) Expire(now time.Time) error
    Expire records bounded expiry events before releasing incomplete groups. The
    deadline is fixed by first admission; duplicate traffic cannot extend it.

func (r *Receiver) Receive(ctx context.Context) (Message, error)
    Receive transfers the next complete message and releases its store charges.
    Optional text decoding runs outside the store lock; decoder failure
    is retained in Message.DecodeError. An available queued message takes
    precedence over ctx. Unsupported UDH language declarations bypass all
    decoders and return ErrUnsupportedNationalLanguage in DecodeError without
    undoing admission/ACK.

func (r *Receiver) Stats() Stats
    Stats reports current bounded-store occupancy under the receiver lock.

type References struct {
	// Has unexported fields.
}
    References reserves concatenation references until a first-allocation based
    retention deadline. Share one allocator across sessions in the same sending
    identity/domain if collisions across those connections must be prevented.
    At most MaxLeases live values exist; exhaustion never silently reuses one.

func NewReferences(bits, maxLeases int, retention time.Duration) (*References, error)
    NewReferences creates a concurrent allocator for an 8- or 16-bit reference
    space. Retention must cover the peer's expected reassembly/retransmission
    time.

func (r *References) Bits() int
    Bits returns the immutable reference width.

func (r *References) Reserve(now time.Time) (uint16, error)
    Reserve expires old leases and reserves a free value without blocking.
    Zero is a valid reference. There is deliberately no early release:
    a submission timeout or even a positive response does not prove peer
    reassembly has ended. Callers supplying time must use a consistent clock for
    this allocator.

type Segment struct {
	Fields  pdu.SMFields // owned per-segment provenance, including ordered TLVs
	Payload []byte       // user data with UDH removed
	Concat  *Concatenation
	UDH     []byte // non-concatenation elements, in original order
	Ports   []byte // identity bytes: UDH port IE, or ordered port TLV tag/value pairs
	Receipt bool
}
    Segment owns both original fields and extracted metadata. Receipt payloads
    remain raw and bypass concatenation; no receipt dialect is inferred.

func ParseSegment(fields pdu.SMFields) (Segment, error)
    ParseSegment classifies receipts before concatenation, rejects incomplete
    SAR, mixed UDH/SAR and malformed UDH, and retains unknown UDH elements and
    TLVs. It copies the input, but is not a versioned SMPP validator. Standalone
    callers must use Codec for command/field/TLV validation before admission.

type Stats struct{ Groups, BufferedBytes, Queued, Tombstones, Events int }
    Stats is a synchronized accounting snapshot, not a reservation of capacity.

type Text struct {
	Source, Destination pdu.Address
	Text                string
	ServiceType         string
	RegisteredDelivery  uint8
	Optional            tlv.Fields
}
    Text is a logical message before encoding and segmentation. Optional
    values are cloned into each segment; generated SAR/payload tags must not be
    supplied.
