Initial stable release of the general-purpose Go SMPP SMS library.

Requires **Go 1.26 or newer**. Module: `github.com/skill215/smppkit`; root
package: `smpp`. Apache-2.0, with no third-party runtime module dependencies.

```sh
go get github.com/skill215/smppkit@v1.0.0
```

## Included

- Explicit SMPP 3.3, 3.4 and 5.0 SMS profiles; concrete PDUs, standalone
  versioned Codec, Client/Server and a shared bounded Session runtime.
- Documented standard/customer TLVs in 3.4/5.0; all TLVs rejected in 3.3.
- Text encoding, automatic multipart sending, per-segment results, bounded
  receive reassembly, explicit memory ACK and expiry handling.
- submit_multi, data_sm direction/transaction validation, outbind and alerts
  within the documented version/role matrix.
- Compilable examples, independent wire fixtures, race/fuzz/resource checks,
  allocation/copy benchmarks and a v1 API compatibility policy.

## Boundaries

This release covers the documented SMS subset, not every command or peer dialect.
Broadcast, historical excluded 3.3 commands and standard high-level 3.3 multipart
remain unsupported. GSM7 is unpacked; strict UCS-2 and explicit UTF-16BE policies
are separate. External SMSC interoperability remains unverified; the legacy
simulator evidence covers only its documented SMPP 3.4 UDH path.

Ordinary submission acceptance is not final delivery. Uncertain requests are not
retried automatically. Memory ACK is not durable admission; persistence, routing
and business delivery tracking belong to applications.

**This library is AI-written using OpenAI Codex under maintainer direction.**
Passing tests and agent review do not constitute an independent human audit or
standards certification.

## Evidence

The implementation candidate passed local Go 1.26.4/1.27.2 build, vet and race,
11 timed fuzz targets, a ten-minute race resource workload and 80 benchmark cases.
One Go 1.26.4 fuzz shutdown failure was preserved and investigated as a matching
toolchain coordinator cancellation defect; it was not hidden or treated as a
passing run. See the historical R3 record for its limits.

Candidate `4749b177` passed remote CI on its first attempt with Go 1.26.10 and
1.27.3: formatting, build, vet, full race and all 11 fuzz targets at five seconds
and two workers each. Final publication also requires successful main and tag
CI for the exact release commit; their links are appended below by the workflow.
