# v1.1.0 G1/G2 validation

Date: 2026-10-29 (Asia/Shanghai). Go 1.26.10 linux/amd64, WSL2, Ryzen 7 6800H.
Uncommitted checkout based on e42bd08 with prior logging/UDH increments preserved.
This increment implements G1/G2 and updates G4's design to include pure construction.
G3 active keepalive and G4 parsing/construction remain planned. No sms-fw changes,
external interconnection, Go 1.27 run, commit, push or release occurred.

## Implemented and reviewed

ReadFrame, ParseHeader, WriteFrame and FrameHeader live in codec. Codec.Read and
ReadBind use the same bounded acquisition primitive. DecodeError/DecodeErrorKind
wrap failures without removing existing sentinel, FieldError or I/O/extension
causes. Raw operations do not validate body semantics; typed Codec retains its
strict rules. Framing and safe diagnostic contracts are in [framing.md](framing.md).
The [source hashes](validation/v1.1.0-framing-source.sha256) identify changed Go
implementation/tests/example at the validated state.

Review covered limit checks before allocation/I/O, short-read zero-tail exclusion,
exact consumed counts and clamped capacity, single-write partial-error reporting,
owned results, no transport ownership/background work, and classification at
mandatory/TLV/extension boundaries. Decode does not claim stream consumption;
HasHeader/HeaderValid/FrameComplete are distinct. HeaderValid deliberately does
not imply a matching supplied slice length or valid body. Error() never formats
arbitrary cause text. Existing causes remain available for errors.Is/As.

The independent address-edit fixture initially had a one-byte arithmetic error
in its hand-written lengths; the fixture was corrected to 49/51 bytes before
validation. Production validation was not relaxed to accept it.

## Coverage and limitations

New tests exercise every incomplete prefix of a 20-byte frame, injected transport
errors, exact caps/default/invalid caps, fragmented/coalesced data, invalid headers,
raw byte equality, zero/partial/full-error writes, malformed mandatory/TLV fields,
duplicate standard TLVs, omitted negative responses in all versions, unknown
private commands, extension identity/privacy, bootstrap failures, concurrent shared
Codec use and independent address-edit bytes with binary UDH/duplicate unknown TLVs.
Existing response correlation, Session lifecycle, supported PDU/encoding/multipart
and ownership tests are reused. There is no new automatic NACK, recovery, retry
or peer dialect relaxation. Invalid Writer counts violate io.Writer and are
reported as io.ErrShortWrite; no useful progress can be inferred from them.

The [development API snapshot](api-v1.1.0.txt) was generated with Go 1.26.10 and
reviewed against the retained v1.0 baseline. Additions are framing/error APIs plus
the earlier Logger and UDH sentinel. The earlier Request result-name change does
not alter its Go function type. No old methods or required extension methods were
removed/added. The snapshot is review evidence, not an automated compatibility proof.
Go remains 1.26; /doc/ remains ignored. Reference code/data are not copied into tests.
