# v1.1.0 UDH language-protection validation

Date: 2026-10-29 (Asia/Shanghai). Go 1.26.10 linux/amd64, WSL2, Ryzen 7 6800H.
Uncommitted development checkout based on e42bd08, including earlier optional
logging changes. This increment updates the approved design/roadmap and implements
U1 only. G1/G2, active heartbeat and G4 are planned, not validated features.
No reference repository changes, external interconnection, commit or push.

## Implementation and review

- Prepare rejects AdditionalUDH IE 0x24/0x25 before encoder/fallback calls.
- Requested Receive decoding reports ErrUnsupportedNationalLanguage, empty Text
  and Decoded=false. The received payload, original fields and per-segment UDH
  remain owned and available. No decoder callback runs for these declarations.
- Raw-only reception and receipts keep their previous behavior. Codec still
  round-trips the independent raw deliver_sm frame without language interpretation.
- All table values/custom encoders are conservatively covered; full language-table
  semantics, packed septets and general UDH parsing APIs are not implemented here.
- Existing admission, ACK, duplicate/tombstone and multipart consistency logic is
  unchanged. Decode failure does not discard data or retract memory admission.
- Review checked that queued messages always retain at least one owned Segment,
  multipart non-concatenation UDH matches, decoder work remains outside the lock,
  and bytes inside other IE values/payload are not mistaken for declarations.
- No private consumer fixture/code was copied; the deliver_sm sample is hand-built
  from public wire layouts and the documented national-table example.

Full race execution needed local loopback-listening permission for existing
TCP/TLS integration tests. The new fuzz command had an external 45-second cap;
it finished normally in 5.076 seconds. Other existing fuzz targets ran their seeds
through full tests but were not rerun as timed fuzz campaigns in this increment.
The new target is added to CI; no remote CI or Go 1.27 run is claimed here.

Independent regressions include 3.4/5.0 deliver_sm bytes, both language IE IDs,
zero/reserved table IDs, malformed semantic widths, duplicate declarations,
unknown IE prefixes, multipart reverse order/conflicting tables/late duplicates,
raw-only ownership, existing receipt bypass and IE length crossing UDHL.
The sender callback guard covers all three protocol versions. Existing multipart,
capacity, concurrency and Codec fixtures are reused by the full race run.

The public addition is message.ErrUnsupportedNationalLanguage; the historical
v1.0 API snapshot is preserved. No existing interface gains required methods.
Go remains 1.26, /doc/ remains ignored, and the shared Session/Codec architecture
and the existing logging implementation are preserved.
