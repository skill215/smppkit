# v1.1.0 logging validation (local, unreleased)

Date: 2026-10-29. Toolchain: Go 1.26.10, linux/amd64 under WSL2.
This record covers the local implementation of [issue #1](https://github.com/skill215/smppkit/issues/1).
It does not announce a release, remote CI result, or external interoperability.
The module minimum remains `go 1.26.0` and no runtime dependency was added.

## Scope and review

- Add `Config.Logger *slog.Logger`; nil uses a shared DiscardHandler. Logger
  configuration applies to shared Session, Client and Server setup.
- Emit safe setup/lifecycle/request diagnostics. Arbitrary error text, addresses,
  credentials, message IDs, payloads and TLV values are not logged.
- Keep logging outside locks. Close remains independent of handlers; the
  existing expiry loop emits one terminal record and Wait joins that work.
  Handler latency can extend Request/Wait/handshake return times.
- Preserve caller contexts in Request and setup diagnostics. Internal timeout
  or Serve cleanup must not substitute an already-canceled internal context.
- Keep the original versioned Codec, three-goroutine Session, wire bytes,
  request outcomes, ACK behavior and retry policy. Heartbeat scheduling (#2)
  is not implemented. Reference repositories were not modified.

Review found two avoidable allocation sites in an initial enabled-event path;
the final helper uses a fixed-capacity attribute buffer and constant event text.
Default logging also returns before inspecting application-defined errors.
These are implementation observations, not public allocation guarantees.

## Executed checks

All final checks below passed:

```sh
go build ./...
go vet ./...
go test -race -count=1 -timeout=90s ./...
go test ./codec -run='^$' -fuzz=FuzzDecode -fuzztime=5s -parallel=2
go test ./codec -run='^$' -fuzz=FuzzEncodeSM -fuzztime=5s -parallel=2
go test . -run='^$' -bench='Benchmark(LoggingEvent|SessionLogging)$' \
  -benchmem -benchtime=200ms -count=3 -cpu=1
go run ./examples/logging
```

Runs used `GOTOOLCHAIN=local`, `GOWORK=off`, `GOPROXY=off`, and temporary Go
build/module caches. An initial unprivileged full test attempt could not bind
loopback sockets (`operation not permitted`). Final full checks ran with the
required local-network permission; no tests were skipped to hide that failure.

The two timed fuzz targets exercised 328,390 and 304,103 inputs respectively;
both completed normally. Codec code did not change. The remaining fuzz targets
ran only their seeds as part of the ordinary full test suite, not timed fuzzing.

The Client and Server examples were built and run over loopback TCP for SMPP
3.3, 3.4 and 5.0, each with diagnostics disabled and enabled: six successful
submit/unbind runs. Output checks confirmed library records were absent by
default and present when explicitly enabled. The standalone bridge uses a
canceled Dial context and needs no socket. These example exchanges share Codec;
the separate independent-byte tests provide the wire evidence.
