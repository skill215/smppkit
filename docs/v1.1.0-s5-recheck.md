## Correction review

- **RV22:** the correlated-response result is fixed under Session.mu before
  heartbeat cancellation observes it. A completed write and received response
  suppress false timeout retirement; an absent response does not. A response
  with a still-blocked write retains timeout retirement. The check reads the
  completion channel, not unsynchronized writer counters. Queue cancellation,
  ordinary Request cancellation, non-OK responses and first terminal cause retain
  their existing behavior. The completion check is a synchronization observation,
  not a promise that a concurrently finishing write always beats cancellation.
- **RV23:** incoming enquiries are ignored only in Unbinding, after strict Codec
  decoding and negotiated-TLV eligibility. The branch neither enqueues an ACK
  nor allocates inbound admission, changes state, resets the unbind context or
  restarts the scheduler. Business requests remain rejected; Bound enquiries
  remain automatically answered. Crossed-unbind completion and the write/request
  deadlines remain governed by the existing shared lifecycle. Continued incoming
  traffic can affect frame-read timing, but cannot extend those shutdown budgets.
- **RV24:** the matrix now separates explicit ReceiptKeyValue support from
  arbitrary vendor dialects and delivery tracking/aggregation. Compatibility and
  keepalive documentation match the corrected behavior. There is no claim that
  receipt parsing establishes final delivery or that unbind is periodically sent.

The promoted tests retain their explicit limits: the RV22 test controls response
publication under the Session mutex, while RV23 pairs real bound Sessions to
exercise crossing. Independent byte tests separately verify bound responses,
absence of writes during unbind and continued business rejection. Existing
missing-response, blocked-write, window-pressure and crossed-unbind tests provide
the negative controls. No additional test or public API is needed for a newly
identified defect in this recheck, because none was found.
