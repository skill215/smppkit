## Implementation and review

Two Config fields enable the optional scheduler; zero interval allocates no
heartbeat channels/timer/goroutine. The scheduler reuses the shared Request path,
sequence map, ordinary window and sole writer. It has one timer and at most one
probe; full capacity never queues timer ticks. See [keepalive](keepalive.md).

Review checked admission and retirement linearization, state/sequence ownership,
lock order (Session.mu before writeJob.mu for automatic write admission), no I/O
or logger invocation under those locks, first terminal cause, cancellation byte
outcomes and Wait ownership. Unbind prevents both later heartbeat retirement and
queued probes from starting. Already active frames finish under WriteTimeout so
an orderly unbind can still write its ACK. Shutdown does not drain business work.
Read and write timeouts remain independent. No reconnect or request replay exists.

The only additive public APIs are Config.EnquireLinkInterval,
Config.EnquireLinkTimeout and ErrEnquireLinkTimeout. The development API snapshot
was regenerated for all six public packages; the v1.0 snapshot is preserved.
The [source manifest](validation/v1.1.0-keepalive-source.sha256) identifies all
non-ignored project Go sources plus go.mod at validation, including prior local
increments. Earlier manifests describe their own historical states.

## Test coverage and limits

The new independent byte peer covers both endpoint directions in all versions,
pre-bind silence, failed-bind retry, successful-bind start, no tick accumulation,
wrong/duplicate sequences, opposite-direction same-sequence enquiries, rejection,
Generic NACK and wrong opcode. Default-disabled sessions have no scheduled work.

Virtual time tests cover full windows without sequence allocation, queued expiry
behind a blocked business writer, a sent-probe deadline preserving a business
Written result, earlier read/write deadlines, explicit probe-timeout override,
local/remote unbind while a probe is pending, remote unbind with queued/active
writes, and a correlated response arriving before Write returns. Concurrent
manual enquiries overlap automatic probes on both endpoints; concurrent Close
and pre-bind Close join the scheduler and leave no automatic window reservation.

The initial independent negative bind fixture omitted the mandatory 3.3 response
body; the fixture was corrected to include its empty C-octet system_id before
recorded validation. Production validation was not weakened.

Continuous window pressure may prevent probes indefinitely; this is documented
local overload behavior, not a peer health guarantee. Logging handlers must
return promptly. Tests do not establish carrier conformance, long-running soak
capacity, guaranteed detection latency under CPU starvation, or network TPS.
DLR helpers, persistence, delivery aggregation and external migration remain
outside this increment.
